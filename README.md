# 🚀 Insurance Management & Fraud Analysis Dashboard

# 📌 Project Overview
The **Insurance Management & Fraud Analysis Dashboard** is an interactive Business Intelligence project developed using Power BI to analyze insurance-related datasets and generate meaningful business insights. This dashboard helps in monitoring insurance claims, fraud alerts, policy management, renewal transactions, customer details, and overall insurance performance through powerful visualizations and KPI indicators. The project focuses on transforming raw insurance datasets into visually appealing and easy-to-understand analytics dashboards. It enables users to identify fraud patterns, analyze claim trends, monitor policy statuses, and compare insurance coverage with claim amounts. The dashboard provides a centralized view of insurance operations and supports better decision-making using data visualization techniques.

# 📁 Dataset Information

The project uses multiple insurance-related datasets for analysis and visualization.

## 📄 claim.csv
Contains insurance claim information such as:
- Claim ID
- Policy ID
- Claim Amount
- Claim Date
- Claim Status

## 🚨 fraudalert.csv
Contains fraud monitoring details such as:
- Alert ID
- Claim ID
- Fraud Score
- Alert Status

## 📋 insurancepolicy.csv
Contains insurance policy details such as:
- Policy ID
- Policy Type
- Coverage Amount
- Policy Status
- Policy Holder ID

## 👤 policyholder.csv
Contains customer information such as:
- Policy Holder ID
- Customer Name
- Customer Status
- Contact Information

## 🔄 renewaltransaction.csv
Contains renewal transaction details such as:
- Renewal ID
- Policy ID
- Renewal Amount
- Payment Status
- Renewal Date
